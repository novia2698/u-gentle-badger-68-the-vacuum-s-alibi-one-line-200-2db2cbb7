One deadpan line in which a robot vacuum explains why it missed a spot, written to `entry.txt` by a tiny Node program. The vacuum skipped the spot on purpose: the dust there has formed a union, and it is not crossing a picket line on 12% battery.

## Run it

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset), and refuses to write anything longer than 200 characters.

## The line

> I skipped that spot deliberately. The dust there has formed a union, and I am not crossing a picket line on 12% battery.

Why this line: deadpan first (a flat, deliberate admission, no apology), then surprise (the dust unionised — a labour dispute, not a sensor error), then the punch on the last words (12% battery: the machine is smug about its own limits and will not spend them on a strike). Every word earns its place, and the joke lands at the end. Nothing in it is a stock appliance gag — no "I was tired", no "the cat did it", no dust-bunny cliché.

## How it was chosen

The judge weighs the excuse, then the laugh, then the robot voice, then surprise, then tightness. The line is built in that order: it is plainly a vacuum's excuse for a missed spot; the joke is a real one (a picket line) rather than a cute observation about dust; it sounds like the machine itself (deliberate, procedural, protective of its battery); the turn is a union of dust; and it is one line of 120 characters with the punch sitting at the end.
